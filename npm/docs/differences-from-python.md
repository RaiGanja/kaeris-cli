# Where the Node port and the Python original are not the same

Everything `kaeris check` reports for a file the original can read is the same: the corpus in
`npm/test/` (151 project directories, 1,504 string pairs, 200 locale files, plus 14,000 further random
pairs run once during development) shows no difference in exit code, `--json`, the human report or
the SARIF file. These are the places where the two are known to differ.

- **XML.** Android, XLIFF and RESX are read with a small parser of this package, not expat. A
  malformed file is refused by both with exit code 2 and the same sentence, but the position in the
  message can differ for rarer errors, and a document that expat rejects for an unusual reason (a
  name character, an encoding declaration that disagrees with the bytes) may be accepted here.
  DOCTYPE and ENTITY declarations are refused by both.
- **CSV.** A bare carriage return inside an unquoted field makes Python's `csv` module raise; the
  original then ends with a traceback (exit 1). The port says so in a sentence and exits 2.
- **Case-insensitive matching of `İ`.** Python treats `İ` (U+0130) as equal to `i` when matching a
  `--glossary` term ignoring case; JavaScript does not.
- **Files the original cannot survive.** A JSON file nested deeper than the Python recursion limit
  ends the original with a traceback; the port stops at 900 levels with a sentence (exit 2). A
  `source` in `kaeris.json` that is a list, or a glossary entry that is not a string, are errors or
  are ignored here and tracebacks there.
- **Operating system errors** are worded like Python's (`[Errno 2] No such file or directory`) for
  the usual codes only.
- **Unicode tables.** Character classes (`\w`, letter, mark, whitespace) come from the Unicode
  version of Python 3.14 in the original and of the Node in use here. No difference has been seen.
- **Commands.** `translate`, `fix`, `init`, `languages` and `quota` are not in this package; they
  print a pointer to `pipx install kaeris` and exit with 2. There is no update notice.

`npm/src/tables.js` holds the patterns and word lists of `kaeris/detectors.py`, generated by
`npm/tools/gen_tables.py`; `tests/test_npm_baselines_are_current.py` fails when it is out of date.
